# PXA.Aerie.Showcase

> A curated architecture showcase for Aerie — Phoenix Ascend’s modular developer framework.

This repository provides a public demonstration of Phoenix Ascend's internal architecture system, **Aerie**. It includes a subset of reusable components, utility types, and example Plumes to highlight the intentionality, modularity, and naming principles that guide our software design.

---

## 🌿 What’s Included

- **PXA.Aerie.Core** — foundational types like `MethodResult<T>`, `IDataRow`, and utility interfaces
- **PXA.Aerie.Constants** — central shared values via the `Lexicon` class
- **PXA.Aerie.LogPlume** — a sample Plume for structured logging and correlation
- **Unit Tests** — lightweight tests that show integration style and expectations

---

## 🛡 What’s Not Included

This is a showcase only. Full Aerie internals such as:
- `PXA.Aerie.Nest` (request flow patterns)
- `PXA.Aerie.Perch` (app bootstrap logic)
- Proprietary Phoenix Ascend application logic  
...are **intentionally excluded**.

---

## 🧭 Purpose

To help clients, collaborators, and hiring teams evaluate:
- Our approach to modular architecture
- How we define Plumes
- Our commitment to developer experience and clarity
